RAG LAB / no backend / learn by doing

From question → grounded answer.

A self-contained simulator of Retrieval-Augmented Generation. Walk through ingestion, chunking, embeddings, vector search, reranking, prompt construction, generation, citations and evaluation — with your own mini knowledge base.

Everything runs locally in this HTML file. The “embeddings”, retrieval and answer are intentionally simulated so you can see the mechanics without an API key.
